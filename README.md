# Actividad 1 - Ejercicios HTML, CSS y JS

Repositorio con los 10 ejercicios prácticos de la Actividad 1 de la materia de Programación Web. Cada ejercicio trabaja un tema distinto de HTML, CSS o JavaScript, y se puede navegar desde el menú principal (`index.html`).

## Ejercicios

**Ejercicio 1 – Hola Mundo**
Página HTML básica con la estructura mínima de un documento (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`), mostrando un encabezado y un párrafo de bienvenida.

**Ejercicio 2 – Formato de texto**
Uso de etiquetas para dar formato a un párrafo: `<strong>` para negrita, `<em>` para cursiva/énfasis y `<br>` para saltos de línea.

**Ejercicio 3 – Enlaces**
Creación de hipervínculos con `<a href="">`, diferenciando entre un enlace externo que abre en pestaña nueva (`target="_blank"`) y un enlace interno que abre en la misma pestaña.

**Ejercicio 4 – Imágenes**
Inserción de una imagen con `<img>`, configurando `src` (la ruta), `alt` (texto alternativo por si la imagen no carga) y `width` para el tamaño.

**Ejercicio 5 – Texto e imagen combinados**
Página estilo blog personal que combina párrafos, una imagen y un enlace con URL completa, integrando lo visto en los ejercicios anteriores.

**Ejercicio 6 – Estructura semántica**
Organización de una página usando las etiquetas semánticas `<header>`, `<section>` y `<footer>` para separar cabecera, contenido y pie de página.

**Ejercicio 7 – Listas**
Página de una receta usando una lista ordenada (`<ol>`) para los pasos y una lista desordenada (`<ul>`) para los ingredientes, con una lista anidada dentro de otra.

**Ejercicio 8 – Horario de clases**
Tabla construida con `<table>`, `<thead>` y `<tbody>`, usando `colspan` para combinar celdas. Se le dio estilo con un archivo CSS externo, incluyendo colores distintos según el tipo de clase.

**Ejercicio 9 – Formulario de contacto**
Formulario con `<form>`, `<label>` y varios tipos de `<input>` (texto, correo, teléfono) más un `<textarea>`, con validación `required` de HTML5. El CSS usa variables (`:root`) para los colores y layout en cuadrícula para acomodar los campos.

**Ejercicio 10 – Conversor de temperatura**
Calculadora en JavaScript que convierte grados Celsius a Fahrenheit con la fórmula `F = (C × 9/5) + 32`. Valida que el campo no esté vacío y que sea un número antes de calcular, y muestra el resultado en un campo `readonly` sin recargar la página.
